Machines

Every machine running sys0 lends its spare capacity at the lowest priority, so its owner never notices.

Crash reports

When sys0 or sys1 crashes on any machine, the report lands here with nothing personal in it: no names, addresses, paths or app data, only the version, OS and where in sys1's code it happened.

Apps on the pool

If a machine crashes or goes offline, its apps move to another machine automatically.

Pooled storage

App data and backups are encrypted on the machine they come from, then copied to several machines. Machines that hold copies can't read them.

Recovery key

Everything in the pool is encrypted with a key that lives on this node. If this node's disk is lost, the data can only be recovered with this key. Copy it somewhere safe, like a password manager.

Marketplace

Only packages that your connected machines can run are shown as available. Every package is verified before it can be deployed.

Add a machine to the pool

  1. Install sys0 on the other machine: download it from the sys1 website or your package manager.
  2. Paste a join code into the installer when it asks.
  3. That's it. sys0 goes quiet and the machine appears here.

Your own machines can also run virtual machines, native programs and apps without a password. Keep this code to yourself.

Machines lent by others only run sandboxed apps, with no access to their owner's network.
