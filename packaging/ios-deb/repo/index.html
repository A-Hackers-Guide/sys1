sys1 for jailbroken iPhones and iPads

Add this repository to Sileo, Zebra or Cydia, then install sys0. It lends your device's spare power to a sys1 pool at the lowest priority, only while it's charging.

Repository
https://a-hackers-guide.github.io/sys1/cydia/

Add to Sileo · Add to Zebra · Add to Cydia

Then join a pool once, from a terminal on the device:

sudo sys0 join <join code> --no-service

Rootless jailbreaks (Dopamine, palera1n rootless), iOS 15 and later. Never in the App Store. More about sys1 on iPhone and iPad.
