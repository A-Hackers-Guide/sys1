Two apps, everywhere.

Install sys0 on every machine that lends its power. Run sys1 on the one that coordinates. The node is a client too, so one computer is already a working pool.

sys0 · the client

Install it, then forget it.

A friendly setup wizard, then it disappears into the background.

  • Lowest CPU and disk priority your OS offers
  • Takes no new work on battery or when the machine is busy
  • Runs apps in locked-down containers
  • Starts with the machine; restarted by the OS if it ever dies
sys1 · the node

One dashboard for every machine.

Machines, apps and the marketplace in one live view.

  • Places each app on the machine with the most room
  • Moves apps when machines leave or keep crashing
  • Marketplace that shows only what your machines can run
  • Cloudflare Tunnel and GitHub Actions built in

When something breaks, it moves.

Apps can save progress to a small checkpoint file. If a machine fails, the app carries on somewhere else from that checkpoint.

It crashes

sys0 restarts the app, waiting 0.5s, then 1s, 2s, 4s.

Five in a row

sys0 stops trying on this machine and sends the app's checkpoint to the node.

It moves

The node picks a different machine and sends it the app with the checkpoint.

It resumes

The app starts from its checkpoint. A machine that just goes offline is replaced within about 15 seconds.

Powerful, and safe by default.

Anyone can lend you a machine, and you can lend yours to anyone. Both sides are protected.

Your machine, your rules

Mark a machine as yours or as shared. Shared machines only ever run sandboxed containers, and the client enforces it.

Nothing to impersonate

TLS 1.3 with the node's certificate pinned in the join code. No certificate authority in the middle.

Signed packages

Third-party apps need an Ed25519 signature from a key you chose to trust. Change one byte and it won't deploy.

Survives the power cord

Every change is written to a checksummed, fsync'd journal before it happens. Unplug the node and it picks up where it left off.

A dashboard only you can open

Bound to localhost and locked with a private key, with strict CSP and protection against CSRF and DNS rebinding.

Read every line

Public domain, three small dependencies, no CGO, no telemetry. The security model lists what's still open, too.
